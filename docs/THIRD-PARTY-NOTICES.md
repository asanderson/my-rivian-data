dependency sources, including target-specific and development dependencies, and
the bundled React runtime packages. This is intentionally broader than the set
linked into the Linux executable. Build-tool packages are obtained separately by
the setup scripts and retain their own licenses.

The Rust 1.99.0 library notices are in `dependency-licenses/rust-1.99.0/`.
Project source uses the repository's GNU GPLv3 license (`GPL-3.0-only`);
these notices preserve the separate terms of third-party dependencies.
